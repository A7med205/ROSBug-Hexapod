# ROSBug Hexapod

ROSBug is an open-source, Raspberry Pi-based hexapod robot with an onboard
camera, printable CAD, physical-robot software, and a ROS 2 Gazebo simulation.
The Raspberry Pi sends timed points for all 18 joints to a Servo 2040 in
batches over USB. The Servo 2040 runs Pimoroni MicroPython and treats each
batch as an opaque playback job: it validates, calibrates, and applies the
points without knowing whether they were generated by the gait core, posture
core, or another compatible producer.

Hardware and simulation use the same model, inverse kinematics, gait and
posture generators, keyboard mapping, and motion coordinator. Only their
transport adapters and actuator backends differ.

![Complete ROSBug Hexapod CAD assembly](docs/full_cad.png)

## Highlights

- Shared, transport-independent Python motion core
- Tripod translation, rotation, diagonal, and orbit gaits
- Smooth elevation, pitch, and roll posture control
- Raspberry Pi to Servo 2040 binary batch protocol
- Pimoroni MicroPython firmware with per-servo calibration
- ROS 2 Humble, Gazebo Sim, RViz, and Docker support
- Editable Onshape CAD and print-ready STL files

## Quick start

### Physical robot

Deploy the runtime directories to the Pi, install the host dependencies, copy
the MicroPython application to the Servo 2040, and start the board interface.
The complete procedure, including BOOTSEL recovery, is in
[Hardware setup](docs/hardware-setup.md).

```bash
python3 -m hardware.board_interface --port /dev/ttyACM0
```

### Docker simulation

On a Linux host with Docker and X11 available:

```bash
./run_sim_docker.sh
```

See [Simulation](docs/simulation.md) for native ROS 2 setup, launch variants,
adapter parameters, and Docker options.

## Repository overview

```text
ROSBug-Hexapod/
├── cad/stl/                         printable mechanical parts
├── common/                          shared keyboard input
├── gait_core/                       tripod gait generation
├── posture_core/                    elevation, pitch, and roll generation
├── robot_core/                      model, IK, coordination, and batch types
├── hardware/                        Pi adapter and Servo 2040 MicroPython code
├── ros2_ws/src/hexapod_sim/         ROS 2 simulation package
├── docs/                            guides, diagrams, and demonstrations
├── Dockerfile
├── run_sim_docker.sh
└── requirements.txt
```
